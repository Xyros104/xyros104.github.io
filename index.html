HomeServer Backup connects a privately operated home server to its owner's Google Drive account to store and retrieve encrypted backups.

What the application does

The server runs Paperless for document management. Its backup process saves document files, the application database and configuration needed for recovery. Restic encrypts backup contents before uploading them to the owner's designated Google Drive backup folder.

The connection also allows the operator to check stored backups and download them for restore verification. Recovery requires the backup password held by the operator.

Optional document intake copies files from the operator's selected Drive Inbox into Paperless for local OCR. Originals are preserved and moved to Imported after confirmed success, or to Review when processing is unsupported or uncertain.

Why Google Drive access is requested

The application needs to read and write backup files in an existing Drive repository. Google authorization covers Drive file access; the deployment is configured to work within folders selected by the operator.

This application is for the operator's personal use. There is no public account registration or document-upload service on this website.

Personal-use terms

The operator manages the application, its Google authorization, backup retention and recovery password. Backup completion and restore results must be checked by the operator; a stored backup is not itself a guarantee of recoverability.

Support contact details are provided on the application's Google authorization screen.
