Data handling

Privacy notice

HomeServer Backup is a private, operator-controlled integration for encrypted backups and document intake in the operator's own Google Drive account.

Last updated: 26 October 2026

Information accessed and its purpose

The application accesses Drive file and folder information and backup file contents to upload, locate, check and restore encrypted backups. Backups contain Paperless document files, database contents and configuration, and may include other applications configured by the operator.

When document intake is enabled, it downloads copies of documents from the selected Inbox to the private Paperless server for local OCR and organization. It records file identifiers, names, content hashes and processing results. Successful originals are moved to Imported; unsupported or uncertain results are moved to Review. Originals are preserved.

Drive authorization permits access to Drive files generally. The deployment is configured to operate within folders selected by the operator; that folder setting is not a separate Google permission boundary.

Storage and protection

Restic encrypts backups before they are uploaded. Local backup repositories and protected restore-test staging are maintained on the private server. The operator stores the recovery password independently.

Intake documents and their local processing copies are readable by the private server for OCR; they are not separately encrypted by restic until backed up. Downloaded copies and processing records remain in protected local storage until the operator applies a retention policy.

Google authorization credentials are stored in protected server configuration. Connections to Google's APIs use HTTPS. Google handles data stored in Drive according to its own policies.

Sharing and other uses

This application uses Google data for backup, verification, recovery and document intake. It does not sell that data or use it for advertising, profiling or AI model training. Optional document AI suggestions are generated on the private HomeServer using Ollama and a locally stored Qwen model. Document text is processed locally; no document contents are sent to an external AI provider, and cloud inference is disabled. Short, unambiguous letters may be filed automatically after local validation: suggested metadata is applied and Inbox is cleared. Letters that are too long, uncertain or cannot be processed retain Inbox and appear in Needs attention for operator review. Original documents, ownership and existing correct metadata are preserved. Local suggestion caches, processing queues and rollback records may contain derived document metadata. The model is not trained on these documents.

Use of information received from Google APIs is limited to the purposes described here and is intended to comply with the Google API Services User Data Policy, including its Limited Use requirements.

Retention, deletion and revocation

The operator controls backup retention and deletion in the backup repositories and Google Drive. Revoking the application's Google access stops future authorized access; existing backups remain until the operator removes them.

The operator can revoke the connection through their Google Account settings. Removing server-side credentials or revoking access does not recover a lost backup password.

This website and future features

These information pages contain no analytics, advertising, sign-in forms or document-upload forms. The hosting provider may process ordinary request metadata when serving the pages.

This notice covers the backup connection and optional document intake described above.

Support contact details are provided on the application's Google authorization screen.
